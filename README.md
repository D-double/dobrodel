# СК Добродел — Официальный сайт строительной компании

Современный веб-сайт строительной компании **«Добродел»** (Санкт-Петербург и Ленинградская область), разработанный в эстетике и архитектуре референсного премиального шаблона TemplateMonster #569703 (VictoryClub).

---

## 🏗 О компании и контенте
Сайт полностью укомплектован реальными данными, услугами, контактами и статьями строительной компании «Добродел» (ранее размещенными на `skdobrodel.orgs.biz`):
- **Специализация:** Строительство коттеджей из клееного бруса, каркасных домов по скандинавской технологии, домов из газобетона, капитальная реконструкция деревянных и блочных строений, монолитные фундаменты, бани и комплексное благоустройство участков (дренаж, выравнивание, мощение).
- **Контакты:** `+7 (981) 188-35-84`, WhatsApp, Telegram.
- **Регион:** Санкт-Петербург и вся Ленинградская область.

## 🎨 Стилистика дизайна (по референсу #569703)
- **Шрифтовая пара:** 
  - `Oswald` — мощные, акцентные заголовки в верхнем регистре (шрифтовой стиль референса).
  - `Inter` — высокая читаемость основного текста, карточек и таблиц.
- **Цветовая палитра:** Глубокий темный фон (`#0b1118`, `#131b26`), теплый золотисто-янтарный строительный акцент (`#e5a93c`, `#f59e0b`), благородный изумрудный (`#10b981`) и тонкие контрастные разделители.
- **Визуальные маркеры:** Акцентные линии eyebrow badges (`w-8 h-px bg-amber-400`), пульсирующий статус активных бригад, карточки с эффектом стекла и мягкого свечения, интерактивные бейджи.

## ⚡ Функционал сайта
1. **Фиксированный Header** с быстрым доступом к звонку, WhatsApp и кнопкой вызова инженера.
2. **Hero-блок** с мощным слоганом, счетчиками ключевых показателей компании (14+ лет опыта, 380+ объектов, 10 лет гарантии, 0 руб. выезд).
3. **Каталог 8 услуг** с характеристиками, ориентировочными ценами и кнопками быстрого заказа расчета.
4. **Интерактивный калькулятор стоимости строительства** в реальном времени с выбором технологии, площади, фундамента, комплектации и формы отправки сметы.
5. **Портфолио с фильтрацией по категориям** (Брус, Каркас, Газобетон, Реконструкция, Бани, Ландшафт) и полноэкранным просмотром (Lightbox).
6. **Пошаговый регламент работы (01–05)** от бесплатного выезда инженера до сдачи ключей.
7. **Блок преимуществ и гарантий** (собственная спецтехника, русские бригады со стажем от 8 лет, смета по договору, еженедельные фотоотчеты).
8. **Раздел статей и новостей** компании (экспертные советы по фундаментам, дренажу, отделке блок-хаусом и саунам).
9. **Отзывы реальных заказчиков** с верификацией районов Ленобласти.
10. **Интерактивный FAQ (аккордеон)** с ответами на ключевые вопросы.
11. **Форма заявки на выезд инженера** и карта районов обслуживания СПб и ЛО.
12. **Плавающая кнопка быстрой связи (FAB)** (WhatsApp / Telegram / Телефон).
13. **Всплывающее модальное окно** заказа консультации.

## 🛠 Технологический стек
- **JavaScript / React 18**
- **Vite 6** (молниеносная сборка и HMR)
- **Tailwind CSS 3** (кастомные дизайн-токены референса)
- **Lucide React** (современная векторная иконографика)

## 🚀 Запуск и сборка

### Установка зависимостей:
```bash
npm install
```

### Запуск в режиме разработки:
```bash
npm run dev
```

### Сборка для продакшн (готово в папку `dist/`):
```bash
npm run build
```

### Предпросмотр продакшн-сборки:
```bash
npm run preview
```
